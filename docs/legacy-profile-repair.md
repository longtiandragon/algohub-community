# 旧账号资料补全

- 已完成注册的学生缺少入学年级、班级或学号时，下一次进入应用会转到独立补全页。管理员不受影响。
- 优先使用已通过学校成员记录，其次待审核记录；缺失字段回退到个人资料。已有值预填且不能在补全页覆盖。
- 保存补全资料会更新原成员记录和个人资料，不重新申请入校、不改变审核状态、不解绑平台账号。未加入学校的用户无需选择学校。
- V52 只将邮箱注册且昵称完全等于“新同学”的学生改为“新同学_XXXXXXXX”，并标记昵称待确认。自定义昵称保持不变。
- 默认昵称提示可引导用户到设置修改；只有实际修改昵称后才清除标记，单独更新简介不清除。完成首次注册引导也会清除标记。

验证：LegacyProfileCompletionTest 覆盖仅补缺项、学校及账号保留、未入校资料、管理员豁免、昵称提示与迁移选择性和重复执行稳定性。frontend/scripts/legacy-profile-smoke.mjs 使用本地演示服务验证路由、预填、390/1440 宽度、提交和昵称提示。

浏览器测试前仅在 algohub_demo 中将 chenyiming 的个人及成员班级置空，年级设为 2024、学号设为 240001，并设置 nickname_needs_review=true。运行脚本会补填班级并修改此演示用户的昵称。
