# 架构

AlgoHub 聚合第三方 OJ 记录，不执行代码评测。Vue 前端调用 Spring Boot `/api`；开发由 Vite 代理，生产由反向代理转发。后端检查身份、学校、归属与资源权限。PostgreSQL 保存用户、平台记录、统计、社交和管理数据，Flyway 执行迁移；Redis 保存会话、令牌失效、限流和短期授权状态。

平台适配器通过统一 HTTP 客户端处理限流、超时、防护页与响应大小。数据库同步队列使用租约和执行编号领取任务，外部请求完成后核验执行权再写入；失败保留旧记录。

浏览器脚本利用用户自己的源站会话读取记录，经连接授权发送必要数据给导入接口。同步凭据敏感，不应上传至公开讨论；服务端校验导入归属和范围。浏览器自报时间不等同于独立验证的首次通过。

统计与动态受隐私、学校、归属和数据可信度约束。平台总量、已收录明细、有时间的历史为不同指标。JWT 和平台登录态加密密钥位于数据库外；轮换前分析会话失效和既有密文解密影响。贡献 CI 使用临时服务与虚构数据，与正式部署分离。
