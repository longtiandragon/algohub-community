# QOJ 浏览器同步

入口：平台账号中的 QOJ 卡片 → 浏览器同步，或 `/qoj-sync`。

1. 先按用户名添加 QOJ 账号。新账号为浏览器模式的个人关注，不要求完成当前不支持的公开资料归属验证；已有已验证账号仍兼容。
2. 安装页面提供的 `algohub-qoj-sync.user.js`，生成该账号的连接码。
3. 在已登录同一账号的 QOJ 页面把语言切为 English，点击右下角「AlgoHub 同步」并粘贴连接码。

浏览器同步本身无需复制 Cookie。脚本仅上传 AC 提交编号、账号、题号、标题、语言和带时区的通过时间。默认面板宽 188px，设置展开后宽 260px。

可以选择自动同步（授权 90 天，随时撤销），间隔 1–12 小时，默认 6 小时，仅在 QOJ 页面打开时运行。手动重新检查仍有服务端五分钟限频保护。

脚本先读取全部可见 AC 分页，检查重复记录、非末页长度、账号、结果与时间，再复查第一页和主页通过题单；全部一致后才上传。比赛隐藏题或主页题单尚未更新造成不一致时停止本轮，不报告成功。

后端分页先暂存，最后一页完成后事务更新提交、通过题与每日统计。记录标为 `USER_REPORTED`；未验证账号用于个人统计，不能将其描述为自动获得公开排行或动态资格。公开范围仍受账号归属和隐私校验约束。导入不会覆盖独立核验过的时间，也不会据此标记源站历史完整。

验证：`npm run test:qoj-script` 检查解析与分页异常；`QojBrowserImportTest` 检查原子导入、幂等、归属与过期票据、锁等待后的权限复查、可信时间保护和统计链路。
