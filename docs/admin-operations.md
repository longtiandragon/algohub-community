# AlgoHub 管理操作

正式站管理员通过 `https://admin.algohub.top/` 登录，不需要加入学校或绑定 OJ 账号。本地开发仍使用 `/admin/login`。主站旧管理地址会转到新域名，主站 `/api/auth/login` 密码登录接口已关闭；邮箱验证码登录不受影响。

生产 Nginx 配置保存在 `deploy/nginx-production.conf` 与 `deploy/nginx-admin.conf`，共用现有前后端进程。管理域名使用独立 HTTPS 证书和主机范围的登录 Cookie。邮件 From 显示名统一为 AlgoHub，真实邮箱仍取 SMTP 发件配置。

## 学校与邀请码

1. 管理后台 → 学校与邀请码 → 新建学校，填写学校名称。
2. 点击“生成”生成学校邀请码，点击“复制”，由管理员发给目标学校的同学。
3. 学生在选学校页面填写邀请码后直接入校；未填邀请码的申请在“学生与认证”筛选待审核后处理。
4. 邀请码泄露时点击“换一个”，旧码立即失效；“停用邀请码”关闭该学校的邀请入校入口，仍可申请审核入校。
5. 编辑学校可以修改名称；只有没有成员和教学数据的学校可以删除，避免误删历史记录。

## 学生与认证

后台默认进入学生目录，覆盖全站学生，包括未申请学校的用户。可以按学校、入校状态、年级、班级、OJ 认证和姓名/用户名/学号搜索，后端分页，每页 10/20/50/100 条。“未绑定学校”指没有任何已通过的入校关系，包含待审核、已拒绝和从未申请；管理员不计入学生人数。学校筛选下的审核状态表示该学校的申请状态。

## 公告与资源

管理后台 → 公告与资源管理支持新建、查看、编辑和删除，并按文字公告/资源链接、发布状态筛选和分页。原有四张资源卡片已迁入数据库，前后台使用同一份数据。新内容默认为草稿，只有管理员可见。开启“发布给所有用户”并保存后，内容出现在公告页及学生首页；关闭开关并保存即可撤下。正文为纯文本，保留换行，不执行 HTML；资源链接只接受 http/https。

## 总榜

管理员从侧栏或手机底栏进入“总榜”，可按时间、平台和统计指标查看。管理员不会被要求绑定学生账号，也不展示个人名次卡片。榜单仍按已验证 OJ 账号及现有隐私规则计算，不直接修改成绩。
