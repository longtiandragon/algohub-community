# 学习目标与提醒

学生从侧栏「目标与提醒」进入；手机从「我的 → 目标与提醒」进入。管理员从「管理后台 → 学习提醒」搜索已入校用户，调整要求或发送留言。

## 目标与统计

年级由「管理后台 → 年级配置」维护。当前开放2023、2024、2025、2026级；2023级默认月目标为0（无要求）。以后新增2027级并填写月目标、保存即可，所有年级选择页面重新进入后读取新配置，无需改代码或部署。停止开放旧年级只移除选择选项，不删除成员、成绩或原默认目标。已有旧年级成员可保持原值，修改其他资料。入学年级表示入学年份，不会随自然年自动递增。

- 默认每月要求：2024级60题、2025级50题、2026级30题，其他年级无默认要求。以审核通过的入校年级为准。
- 用户可设置持续的每周、每月计划，清空即取消个人计划。提醒目标取个人计划和学校要求的较高值。
- 管理员可以单独调整每周/月要求；清空恢复默认，0表示免除该项要求。相同设置重复保存不重复通知，变更保留操作人和记录。
- 原「校内动态」的本周目标改名为「本周专项计划」，仍支持平台/分类筛选，独立于持续目标。
- 按北京时间自然周（周一至周日）、自然月统计。先合并已解析/已验证平台账号的同平台同题首次通过时间，再筛选周期；只计准确时间，未知或估算时间不计。不同平台的题分别计数。进度依赖最近同步，解绑账号会影响实时统计。

## 通知安排

北京时间09:00开始：周四发送周进度、每月15日发送月进度、每周一发送上周新通过题数及当前目标。达到目标仍发送完成反馈。15日恰逢周四会收到两种提醒。

每分钟分批生成，每批100名活跃、已入校学生。当天09:00后重启可补当天未生成的消息；跨日停机不会补发错过日期。数据库唯一键防止多个实例生成重复消息。

站内消息永久保留至账号删除，支持分页、已读与全部已读。登录后的各页面显示未读提醒。管理员手动消息附带当前周/月进度，同一用户60秒内只允许一条，重试同一请求标识不会重复入队。

## 邮件和部署

邮件仅使用已验证登录邮箱，不使用公开联系邮箱。用户可关闭邮件通知，站内消息保留。发送前重新检查账号、入校状态、邮箱及接收设置。

生产配置 `prod` 默认开启任务，`REMINDERS_ENABLED=false` 可同时暂停自动生成和邮件队列消费，管理员手动站内通知仍可用。普通本地、demo和测试环境默认关闭；本地调试如需启用，显式设置 `algohub.reminders.enabled=true`，仅使用测试收件人。

生产邮件沿用 `prod,mail` 配置及 `MAIL_HOST / MAIL_PORT / MAIL_USERNAME / MAIL_PASSWORD / MAIL_FROM`。缺少发件服务时保留待发送队列，前后台明确显示未配置/未开启状态。重新启用会消费积压的待发送邮件，启用前应检查队列。

消息和邮件队列同事务落库；每15秒最多发送20封，多实例用数据库租约领取。SMTP超时沿用mail配置的10秒，租约10分钟；失败依次延迟5、10、15、20分钟，最多尝试5次。失败记录在管理员详情可见。SMTP接受后进程崩溃可能导致租约过期后重复投递，这是至少一次交付；“邮件已发出”表示SMTP调用成功，不保证收件箱最终投递。

Flyway V38创建目标、通知、邮件队列和调整审计表，不改写原单周目标。正常启动会自动迁移。真实SMTP送达及生产09:00调度需部署后验证。

## 验证

后端：`cd backend` 后运行 `mvn -Dtest=StudyReminderTest test`。涵盖默认值、个人/管理员优先级、边界、并发去重、越权、邮件重试/退出接收、时区及跨账号首次通过去重。

前端：启动隔离demo后，在frontend运行 `node scripts/reminders-e2e.mjs`，验证真实登录、保存计划、管理员调整/留言、站内接收/已读及390/834/1440宽度。此脚本仅使用8081的demo，要求自动发送关闭。`npm run shots -- reminders admin-reminders --label=reminders --widths=390,834,1440 --themes=light,dark --strict`检查两种主题。
