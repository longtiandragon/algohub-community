# 平台支持与排查

此表描述代码入口，不保证第三方接口持续可用。以 `/api/platforms/capabilities` 和当前账号数据项状态为准；贡献者须遵守源站规则，遇到限制退避，不尝试绕过防护。

| 平台 | 账号标识与归属 | 同步入口与边界 |
|---|---|---|
| Codeforces | 用户名，公开资料验证 | 服务端公开统计、提交、比赛/Rating；限流时保留旧数据 |
| AtCoder | User ID，公开资料验证 | 服务端；外部记录源可能延迟，不能据此承诺实时 |
| 洛谷 | 按用户名查询，公开资料验证 | 公开题单/统计与浏览器记录分开；未知通过时间不伪造 |
| 力扣中国 | userSlug，公开资料验证 | 公开统计及最近记录；完整浏览器导入见 [专门说明](leetcode-browser-sync.md)，不是仅最近 15 条 |
| 牛客 | 数字 UID，公开资料验证 | 服务端统计/练习/Tracker；相同题号需按既有规则去重，不把不同题合并 |
| 码蹄集 | 昵称查候选、数字 ID 定位，公开资料验证 | 服务端；同名须用户确认，不把昵称当唯一 ID |
| 杭电 | 登录用户名；个人关注 | 公开练习记录；不因添加账号而宣称已验证归属 |
| QOJ | 用户名；浏览器模式个人关注 | [浏览器同步](qoj-browser-sync.md)，不提交 Cookie；未验证账号不自动进入公开排行/动态 |
| 蓝桥 | 以当前能力接口和账号页为准，适配器有公开资料验证实现 | 登录态及接口可用性受源站限制；没有验证过的当前线上能力不作承诺 |

记录总量、明细和时间历史分别显示；零、未知、失败不是同一个状态。浏览器自报数据标记为 USER_REPORTED，不冒充源站独立核验。

排查时先记录项目提交、脚本版本、平台、同步方式和脱敏错误。检查是否登录同一源站账号、连接授权是否过期、脚本是否适用于当前域名、分页是否完整、平台题数是否在同步期间变化。遇到 403、防护页或限流等待后重试，不反复提交凭据。问题仍存在时按平台适配模板提交最小复现，不附 Cookie、Token、验证码、真实用户记录或备份。
